# Practiceoptimize scheduler

An AI agent that moves each surgical case from order to post-op follow-up, with human schedulers
approving the high-risk steps.

## Getting started

```bash
npm install
```

```bash
npm run type-check
```

```bash
npm run lint
```

```bash
npm run test:coverage
```

```bash
npm run dev:web
```

Requires Node.js 22. See [AGENTS.md](./AGENTS.md) for the layout, rules, and decisions.
